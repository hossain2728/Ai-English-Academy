# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-13

### Added
- 🎉 Initial open-source release of **AI English Academy**.
- 🗺️ 24-week structured CEFR English learning roadmap (A1 to C1).
- 📐 30 core grammar formulas with clear Bangla explanations and interactive examples.
- 📚 Oxford 3000 vocabulary curriculum categorized into thematic everyday stories.
- 🧠 Built-in Spaced Repetition System (SRS) flashcards for long-term memory retention.
- 🎤 Speaking practice, pronunciation assessment, and shadowing with Web Speech API.
- 🤖 AI Personal Tutor powered by Google Gemini (supporting BYOK and Vercel server environment key).
- ⚡ Full-stack SSR with TanStack Start & Nitro optimized for seamless Vercel deployment.
- 🎨 Modern, mobile-responsive UI with Tailwind CSS v4 and Radix UI primitives.
- 🔒 Client-side privacy guard: local storage management without tracking user data.
