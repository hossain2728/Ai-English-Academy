# Security Policy / নিরাপত্তা নীতি

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability / নিরাপত্তা দুর্বলতা রিপোর্ট করা

If you discover a security vulnerability within **AI English Academy**, please do not open a public issue. We take security seriously and ask that you disclose it responsibly.

অনুগ্রহ করে কোনো নিরাপত্তা সংক্রান্ত ত্রুটি পেলে পাবলিক ইস্যু না খুলে দায়িত্বশীলভাবে জানান।

### Contact
- **Telegram:** [@AiEnglishAcademy](https://t.me/AiEnglishAcademy)
- Or contact the maintainers via private GitHub security advisory.

Please provide:
1. Description of the issue
2. Steps to reproduce
3. Potential impact

We will review and address valid security reports promptly. Thank you for helping keep the community safe!
