## 🌟 আমাদের লক্ষ্য (Our Mission)

ইংরেজি ভাষা জানা বর্তমান বিশ্বে ক্যারিয়ার, পড়াশোনা এবং আত্মউন্নয়নের জন্য অপরিহার্য। তবে ব্যয়বহুল কোর্স বা জটিল ব্যাকরণের কারণে অনেকেই মাঝপথে থেমে যান।  
**AI English Academy**-এর লক্ষ্য হলো:

- বাংলা ভাষাভাষী প্রতিটি মানুষের জন্য আন্তর্জাতিক মানের ইংরেজি শিক্ষার পথ সুগম করা।
- কোনো পেইড সাবস্ক্রিপশন বা বিজ্ঞাপন ছাড়া ১০০% উন্মুক্ত রাখা।
- আধুনিক এআই প্রযুক্তি (Google Gemini) ব্যবহার করে সার্বক্ষণিক একজন ব্যক্তিগত গৃহশিক্ষকের সান্নিধ্য দেওয়া।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Frontend:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Routing & SSR:** [TanStack Router](https://tanstack.com/router) & [TanStack Start](https://tanstack.com/start) (Full-Stack Universal Framework)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) + [Radix UI](https://www.radix-ui.com/)
- **Server Engine:** [Nitro](https://nitro.build/) (Vercel Serverless Build Output API v3)
- **AI Integration:** [Vercel AI SDK](https://sdk.vercel.ai/) (`ai`, `@ai-sdk/openai-compatible`) powered by Google Gemini
- **Audio & Speech:** Web Speech API (`SpeechSynthesis` & `SpeechRecognition`)

## 🚀 লোকাল সেটআপ (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন

```bash
git clone https://github.com/<your-username>/Ai-English-Academy.git
cd Ai-English-Academy
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন

```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার করুন (ঐচ্ছিক)

```bash
cp .env.example .env
```

`.env` ফাইলে আপনার Google Gemini API Key দিতে পারেন:

```env
GEMINI_API_KEY=your_google_gemini_api_key_here
```

> _নোট: পরিবেশ ভেরিয়েবল না দিলেও চলবে; ব্যবহারকারী সরাসরি সাইটের Settings থেকেও নিজের ফ্রি Gemini API Key সেট করতে পারেন।_

### ৪. লোকাল সার্ভার চালু করুন

```bash
npm run dev
```

ব্রাউজারে ভিজিট করুন: **`http://localhost:8080`**

## ☁️ Vercel-এ ডিপ্লয়মেন্ট (Deploy on Vercel)

এই প্রজেক্টটি Vercel-এ জিরো-কনফিগ ডিপ্লয়মেন্টের জন্য সম্পূর্ণ অপ্টিমাইজড:

1. আপনার নতুন GitHub রিপোজিটরিতে কোড পুশ করুন।
2. [Vercel](https://vercel.com/)-এ গিয়ে **Add New Project**-এ আপনার রিপোটি সিলেক্ট করুন।
3. প্রজেক্টের Framework হিসেবে **TanStack Start** স্বয়ংক্রিয়ভাবে শনাক্ত হবে (রুট ডিরেক্টরির `vercel.json` এর মাধ্যমে)।
4. (ঐচ্ছিক) **Environment Variables**-এ `GEMINI_API_KEY` যুক্ত করতে পারেন।
5. **Deploy** বাটনে ক্লিক করুন!

├── public/                 # স্ট্যাটিক অ্যাসেট (favicon, robots.txt)

│   ├── lib/                # কোর লজিক (SRS, Speech, Storage, Onboarding)

│   │   ├── _app/           # মূল অ্যাপ্লিকেশন পেজসমূহ
│   │   ├── api/chat.ts     # AI Chat সার্ভারলেস এন্ডপয়েন্ট

│   └── styles.css          # গ্লোবাল স্টাইল ও ফন্টস
